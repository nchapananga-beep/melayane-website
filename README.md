# MELAYANE — Website institucional

Website institucional da **MELAYANE — Investimentos e Serviços**, projecto empresarial em desenvolvimento na Beira, Moçambique.

## Estrutura

- `index.html`: página e secções públicas.
- `styles.css`: estilo responsivo.
- `script.js`: menu móvel e ano automático.
- `assets/favicon.svg`: identidade gráfica provisória.
- `robots.txt`: configuração básica de pesquisa.

## Testar

Abra `index.html` num navegador. Não há dependências nem compilação.

## Publicar com Cloudflare Pages

Ligue o repositório GitHub `nchapananga-beep/melayane-website` a um projecto Cloudflare Pages de site estático.

- Framework preset: **None**
- Build command: **em branco**
- Build output directory: **/** ou **.** (raiz)

Depois de publicado, será disponibilizado um domínio de teste `*.pages.dev`. A ligação de `melayane.co.mz` deve aguardar resolução das questões de DNS na REGISTAR.
